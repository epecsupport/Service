## 3WL Trip Parameters (Brooks' Quick List)
- (All changes must be made when main breaker is Open)
- L - tripping. Overload protection.
- [ I(R) ] current setting defines the maximum continuous current circuit brkr can carry without tripping. [ t(R) ] Long-time delay determines the max duration of an overload w/o tripping
- S - tripping. Short-time delayed short-circuit tripping
- [ I(sd) ] short-circuit current  ---can be delayed by the [ t(sd) ] Tripping time
- I - tripping [ I(i) ]. Instantaneous short-circuit
- G - tripping. Ground-fault
- The [ I(g) ] Ground fault response value together with the [ t(g) ] delay time determines the shutdown of ground-fault currents
