## Replacement Breaker Guide for Powertran MPCs:

### 1-Phase Encapsulated PowerCenters (typically 5 through 15 kVA) "-BW" Series
- INPUT Main CB = Siemens # 3VA51XX-6ED26 ( 65 kA @ 480V )
- OUTPUT Main CB = ABB # SU200 Series ( 10 kA @ 240V )
- OUTPUT Feeder CB = ABB # SU200 Series ( 10 kA @ 240V )

### 1-Phase, Ventilated PowerCenters ( typically 15 thru 100 KVA ) “ -LC “ Series
- INPUT Main CB = None
- OUTPUT Main CB = Siemens # 3VA4150-5ED34 ( 35 kA @ 480V )
- OUTPUT Feeder CB = Siemens # BL Series ( 10 kA @ 240V )

### 3-Phase, Encapsulated PowerCenters ( typically 5 thru 15 KVA ) “ -BW “ Series
- INPUT Main CB = Siemens # 3VA51XX-6ED26 ( 65 kA @ 480V )
- OUTPUT Main CB = ABB # SU200 Series ( 10 kA @ 240V )
- OUTPUT Feeder CB = ABB # SU200 Series ( 10 kA @ 240V )

### 3-Phase, Ventilated PowerCenters ( typically 15 thru 150 KVA ) “ -LC “ Series
- INPUT Main CB = None
- OUTPUT Main CB = Siemens # 3VA4150-5ED34 ( 35 kA @ 480V )
- OUTPUT Feeder CB = Siemens # BDQ Series ( 14 kA @ 480V )
