# QT / EPEC Service Bulletins:

### [Master torque specification guide (600V/800V)](https://raw.githubusercontent.com/epecsupport/Service/main/library/TSB_20251119rev1217.pdf)
References torque values for all 600V and 800V QT/EPEC equipment.  Large file size.

### [Master torque specification guide (600V only)](https://raw.githubusercontent.com/epecsupport/Service/main/library/TSB_20251119rev1217L.pdf)
More compact reference for 600V QT/EPEC equipment only.  Smaller file size.

### [Siemens Position on micro-ohm contact resistance testing, ACB & MCCB](https://raw.githubusercontent.com/epecsupport/Service/main/library/TSB_20260305.pdf)
Document summarizing Siemens' (and therefore QT/EPEC's) position on contact resistance testing of circuit breakers, and the reasons behind this position.

### [Siemens MCCB acceptable termination guide](https://raw.githubusercontent.com/epecsupport/Service/main/library/TSB_20260303.pdf)
Summary of Siemens acceptable terminations for 3VA series MCCBs.  Explains pin connection incompatibility. 

### [Siemens trip unit parameter definitions](https://raw.githubusercontent.com/epecsupport/Service/main/library/TSB_20251212.pdf)
Reference guide for parameters found on Siemens current and legacy trip units.
